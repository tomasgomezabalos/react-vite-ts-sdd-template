# ADR-0003 — Sass/SCSS para estilos

**Estado:** APPROVED

**Aprobación:** 2026-08-22

## Contexto

La plantilla necesita permitir estilos modulares y reutilizables sin incorporar un sistema visual, tokens o abstracciones ficticias antes de que exista una feature aprobada.

## Decisión

- Utilizar Sass mediante el paquete `sass` y la integración nativa de Vite.
- Utilizar sintaxis SCSS.
- Mantener los estilos globales mínimos en `src/index.scss`.
- Permitir `styles.module.scss` para estilos locales de futuros componentes.
- Utilizar `@use` y `@forward` para módulos compartidos; no utilizar el `@import` de Sass deprecado.
- Favorecer variables CSS para valores modificables en ejecución y reservar variables, funciones y mixins de Sass para necesidades de compilación reales.
- No crear una arquitectura de estilos compartida hasta que una necesidad aprobada justifique su reutilización.

## Consecuencias

- Vite compila SCSS sin plugins adicionales.
- La baseline añade una dependencia de desarrollo para el compilador Sass.
- ESLint no analiza archivos SCSS; añadir Stylelint requerirá una decisión separada.
