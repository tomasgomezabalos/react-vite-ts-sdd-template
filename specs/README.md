# Especificaciones

Este directorio está reservado para la visión, las features, los cambios y los informes de validación del producto derivado.

La plantilla no incorpora features de producto. El primer cambio `FULL` podrá comenzar en `specs/001-<nombre>/` y utilizar el identificador `FEAT-001`, siguiendo la clasificación y las plantillas indicadas en `docs/sdd/README.md`.

Las decisiones y especificaciones históricas heredadas de la baseline viven en `docs/platform/` y no deben copiarse ni renombrarse dentro de este espacio de producto.

Los artefactos nuevos utilizarán estado documental y registrarán la entrega en `validation-report.md` conforme a ADR-0009.
